# The Android app (Expo)

Read the root [AGENTS.md](../AGENTS.md) first. This file covers what is specific to the Expo project.

## Expo changes every SDK: check the docs, not your memory

This is Expo SDK 58 (React Native 0.88, React 19.3, TypeScript 6). Before using an Expo or React Native API, read the versioned docs at `https://docs.expo.dev/versions/v58.0.0/` (index of all docs: https://docs.expo.dev/llms.txt), or the `.d.ts` files in `node_modules`.

## Commands

```bash
npm ci                       # install exactly what package-lock.json says
npx expo install <package>   # add a dependency: picks the SDK-compatible version
npx expo run:android         # build and run the development build (Expo Go can't run this app)
npm run typecheck            # TypeScript
npm test                     # unit tests and checks in scripts/ (run with tsx, outside the app's typecheck)
npm run export:web           # the web demo, built for GitHub Pages under /mantide/
npm run e2e                  # Playwright test of that build
```

## Layout

| Path | What |
|---|---|
| `App.tsx` | The single screen: map, header, scale switcher, panels and sheets. No router |
| `src/i18n/` | Every visible string, English (`en.ts`, source of truth) and Italian (`it.ts`) |
| `src/map/` | The MapLibre page (`mapHtml.ts`), its WebView (`MapView.tsx`), photo thumbnails (`thumbs.ts`) |
| `src/geo/` | Boundaries, place names and `locate()`: point → country, region, province |
| `src/gallery/` | Reading the gallery |
| `src/ai/` | Gemma client (`gemma.ts`), the parser of its answers (`parse.ts`), the 12 interests |
| `src/events/` | Sample events and the recommender |
| `src/screens/` | Welcome, Local panel, place sheet, passport, timeline, photo grid |
| `src/stats/` | The passport's numbers |
| `src/state/` | Visited places |
| `src/demo/demo.json` | Demo fallbacks, generated by `scripts/build-demo.ts`: don't edit by hand |
| `e2e/`, `.maestro/` | End-to-end tests: the web demo (Playwright) and the release APK on an emulator (Maestro, in CI) |

## Browser version

`npx expo start --web` runs the same app in a browser. Each piece that needs the phone has a browser twin next to it, picked automatically by Metro: `src/storage.web.ts` (localStorage), `src/gallery/source.web.ts` (the demo gallery from Wikimedia), `src/ai/image.web.ts` (canvas resize), `src/map/thumbs.web.ts`, `src/map/MapView.web.tsx` (iframe). Keep each twin's exports identical to its Android file. `app.config.ts` sets the web base URL only for the Pages build.

## Native code

`android/` and `ios/` are generated (Continuous Native Generation) and ignored by git: configure native behaviour in `app.json` and config plugins, never by hand. Any change to `app.json`, native dependencies or native code needs a new `npx expo run:android`; tag that commit `[native: rebuild]`.
