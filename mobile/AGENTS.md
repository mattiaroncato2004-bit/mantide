# The Android app (Expo)

Project context, decisions and known pitfalls live in the root [AGENTS.md](../AGENTS.md) and [progressi.md](../progressi.md): read them first. This file covers what is specific to the Expo project.

## Expo changes every SDK: check the docs, not your memory

This is Expo SDK 58 (React Native 0.88, React 19.3, TypeScript 6). Before using an Expo or React Native API, read the versioned docs at `https://docs.expo.dev/versions/v58.0.0/` (index of all docs: https://docs.expo.dev/llms.txt), or the `.d.ts` files in `node_modules`.

## Commands

```bash
npx expo install <package>   # always, instead of npm install: picks the SDK-compatible version
npx expo run:android         # build and run the development build (Expo Go can't run this app)
npx tsc --noEmit             # typecheck
npx tsx scripts/<name>.ts    # tests and tools in scripts/ (excluded from the app's typecheck)
```

## Layout

| Path | What |
|---|---|
| `App.tsx` | The home: map, scale switcher, the 4 tabs, photo preview. Tabs are plain state: no Expo Router |
| `src/map/` | The MapLibre page (`mapHtml.ts`), its WebView (`MapView.tsx`), photo thumbnails (`thumbs.ts`) |
| `src/geo/` | Boundaries and `locate()`: point → country, region, province |
| `src/gallery/` | Reading the gallery |
| `src/ai/` | Gemma client (`gemma.ts`), the parser of its answers (`parse.ts`, testable in Node), the 12 interests |
| `src/events/` | Invented events and the recommender |
| `src/screens/` | Galleria, Interessi, Per te |
| `src/state/` | Visited places |
| `src/demo/demo.json` | Demo fallbacks, generated by `scripts/build-demo.ts`: don't edit by hand |

## Native code

`android/` and `ios/` are generated (Continuous Native Generation) and ignored by git: configure native behavior in `app.json` and config plugins, never by hand. Any change to `app.json`, `package.json` or native code needs a new `npx expo run:android`; tag that commit `[native: rebuild]`.
